# 风格选择指南

本技能提供 5 种视觉风格，每种风格对应不同的品牌调性和使用场景。选择时，请考虑你的**内容类型**、**目标受众**和**品牌形象**。

---

## 1. default（默认风格）

**视觉特点**：
- 主色调：暖金色（#c9a96e）+ 米白色背景
- 字体：系统默认无衬线字体
- 布局：卡片式，圆角柔和
- 整体感觉：温暖、有质感、不张扬

**适用场景**：
- 个人 IP、创业故事、生活感悟
- 文化类、教育类内容
- 希望给人"靠谱、有温度"的印象

**不适合**：
- 科技感强的内容
- 需要强烈视觉冲击的营销内容

---

## 2. traditional（中国传统文化风）

**视觉特点**：
- 主色调：朱红（#8b0000）+ 墨黑（#1a1a1a）+ 宣纸米黄
- 字体：书法字体（楷体/宋体）
- 布局：竖排或传统横排，留白多
- 装饰：印章、祥云、山水纹理
- 整体感觉：古典、厚重、有文化底蕴

**适用场景**：
- 国学、历史、传统文化内容
- 书法、茶艺、中医相关
- 希望强调"东方美学"的品牌

**不适合**：
- 现代科技、互联网产品
- 年轻化、潮流化内容

---

## 3. geek（极客科技风）

**视觉特点**：
- 主色调：深蓝（#0a1929）+ 荧光绿（#00ff41）
- 字体：等宽字体（Courier/Consolas）
- 布局：代码块风格，行号，终端感
- 装饰：二进制、代码片段、电路板纹理
- 整体感觉：专业、技术感、极客范

**适用场景**：
- 科技、互联网、AI 相关
- 产品发布、技术分享
- 面向开发者、技术人群

**不适合**：
- 文化、艺术类内容
- 需要温暖感的品牌

---

## 4. cyberpunk（赛博朋克风）

**视觉特点**：
- 主色调：霓虹紫（#bf00ff）+ 品红（#ff007f）+ 青蓝（#00ffff）
- 字体：未来感无衬线字体
- 布局：高对比，大面积色块，故障艺术
- 装饰：霓虹灯、网格线、像素化
- 整体感觉：潮流、前卫、未来感

**适用场景**：
- 潮流品牌、时尚、音乐
- 年轻化、创意类内容
- 需要强烈视觉冲击的营销

**不适合**：
- 严肃商务内容
- 传统文化、教育类

---

## 5. consulting（咨询公司风）

**视觉特点**：
- 主色调：深蓝（#003366）+ 灰色（#666666）+ 白色
- 字体：专业无衬线字体（Arial/Helvetica）
- 布局：严谨、对齐、留白克制
- 装饰：极少，强调数据和逻辑
- 整体感觉：专业、严谨、可信赖（埃森哲/麦肯锡风格）

**适用场景**：
- 企业咨询、商务服务
- 数据分析、行业报告
- 面向企业客户、高管人群

**不适合**：
- 个人 IP、生活化内容
- 需要创意和视觉冲击的内容

---

## 选择建议

### 按内容类型选

| 内容类型 | 推荐风格 |
|---------|---------|
| 个人成长、创业故事 | default |
| 国学、文化、历史 | traditional |
| 科技、互联网、AI | geek |
| 潮流、时尚、创意 | cyberpunk |
| 商务、咨询、企业 | consulting |

### 按目标受众选

| 受众 | 推荐风格 |
|------|---------|
| 大众、朋友、社群 | default |
| 文化爱好者 | traditional |
| 技术人员、开发者 | geek |
| 年轻人、Z 世代 | cyberpunk |
| 企业客户、高管 | consulting |

### 按品牌形象选

| 品牌调性 | 推荐风格 |
|---------|---------|
| 温暖、有温度 | default |
| 传统、厚重 | traditional |
| 创新、技术 | geek |
| 潮流、前卫 | cyberpunk |
| 专业、严谨 | consulting |

---

## 风格对比示例

假设同一句文案："9 月 11 日，三天两夜，我们一起明理。"

| 风格 | 呈现效果 |
|------|---------|
| default | 暖金色标题，米白背景，柔和圆角 |
| traditional | 朱红标题，宣纸背景，楷体字，印章装饰 |
| geek | 荧光绿标题，深蓝背景，等宽字体，代码框 |
| cyberpunk | 霓虹紫标题，黑色背景，发光效果，故障艺术 |
| consulting | 深蓝标题，白色背景，简洁对齐，无装饰 |

---

## 如何切换风格

在调用本技能时，直接说明想要的风格即可：

- "用默认风格"
- "用传统文化风"
- "用极客科技风"
- "用赛博朋克风"
- "用咨询公司风"

如果不指定，默认使用 **default** 风格。
